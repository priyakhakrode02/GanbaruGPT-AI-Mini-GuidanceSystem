GanbaruGPT

Building AI Chat Assistant using OpenAI Model. 
An AI-based chat application that allows users to ask questions and receive AI-generated responses. Users can also view their chat history and delete chats.

Features
- Ask questions and get AI-generated responses.
- View chat history.
- Delete chat conversations.
- Simple and user-friendly interface.

Tech Stack
- Frontend: React.js
- Backend: Node.js
- Database: MongoDB

The goal of this project is to build an AI-powered chat application and learn how to integrate AI with a full-stack web application.
